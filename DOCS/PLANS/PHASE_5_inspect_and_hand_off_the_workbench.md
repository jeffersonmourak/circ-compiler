# Phase 5 — Inspect and hand off the workbench

> **Dependencies:** Phases 0–4 implemented and accepted before this phase begins. Reuse their registry, envelopes, revisions, operations, artifact/session bindings, mutation queue, persistence receipts, diagnostic/result paging, and verified client paths.
> **Warnings:** Read the macroplan, prior phase specs, `DOCS/{preview,wasm-api,sim-protocol}.md`, and `DOCS/decisions/{playground,playground-bench,agent-playground}.md`. Preview and Truth are independent operations, not properties of compile success. A displayed last-good artifact may be stale. Truth pagination does not authorize unbounded enumeration. Share/source/WASM do not contain source-owned images or live RAM. A browser download dispatch is not proof that bytes reached disk.

## Goal

An agent can request and retrieve the exact schematic text, inspect bounded structured topology from a compiled artifact, and request/page an exhaustive or live-pin-filtered Truth table whose scope, held inputs, unknown inputs, cap, images, and provenance are explicit. It can visibly select the workbench view, open Data, change supported preview/Truth/value/editor settings, and hold or clear a top-level source/canvas/Truth highlight through the same application paths as the UI. It can retrieve source, share URLs, and transcript/script text without clipboard permission, and can dispatch provenance-bound WASM or live/source-memory image downloads. Every handoff states its contents and omissions, so source or artifact output is never represented as carrying memory images or a live RAM snapshot.

## Scope

**In scope:**
- Register `circ_request_schematic`, `circ_get_schematic`, `circ_get_topology`, `circ_request_truth_table`, `circ_get_truth_table`, `circ_set_workbench_settings`, `circ_set_view`, `circ_highlight`, `circ_export_source`, `circ_create_share_link`, `circ_download_artifact`, `circ_download_memory`, and `circ_get_transcript`.
- Reuse Phase 1 preview/Truth operations and immutable request stamps; expose bounded retained payloads rather than scraping rendered DOM.
- Return deterministic preview text generated by libcirc with current explicit expansion settings and `color: never`.
- Decode the artifact's `circ.topology.v0.full` section and page components/connections with file-resolved origin frames and artifact-local IDs.
- Reuse compiler Truth where exhaustive/root-preload-compatible and scratch `SimSession` Truth for imported images or filtered live pins; retain one truthful result shape across both paths.
- Refuse RAM Truth, excessive projected work, missing current live state for filtering, errors, stale preconditions, and oversized retained output before claiming a table.
- Persist and visibly apply preview expansion, value format, Truth cap, editor preferences, selected view, and Data-panel open state through existing schema-v2 paths.
- Apply a persistent-until-cleared agent highlight to a current top-level declaration, with temporary human hover/focus overlays restoring it afterward.
- Return source and transcript/script as bounded cursor pages, and return a share URL or explicit codec/cap refusal without using clipboard/share-sheet APIs.
- Dispatch one browser download per WASM or memory call using copied bytes and return an honest receipt with provenance, contents, omissions, filename, media type, and byte count.
- Export either a root live memory snapshot or a source-owned ROM preload, including imported-file preloads, as a raw binary image.
- Prove the complete flow on a multi-file ROM project whose source/share/WASM each omit images and whose required preload is exported separately.

**Explicitly deferred:**
- Adding images, settings, artifacts, or RAM snapshots to the existing share-fragment/source marker format.
- Zip/project bundles, archive manifests, base64 binary result paging, filesystem path selection, upload endpoints, remote storage, clipboard-dependent success, or multi-download batches.
- Claiming a dispatched browser download completed, survived browser policy, or was written to a particular path.
- Editing topology, addressing live runtime components by topology ID, nested live-memory mutation, or treating synthetic layout IDs as runtime IDs.
- New preview character sets, compiler options, topology format versions, compiler/renderer changes, or schema migration.
- Truth over any RAM, unbounded enumeration, hidden pagination-triggered computation, random sampling, or verification scenarios; behavioral scenarios remain Phase 4.
- Persisting highlights, canvas pan/zoom, output payload histories, cursors, or transcript exports.
- Project/file authoring, compile settings, memory mutation, and simulation operations already covered by Phases 3–4.

The fixed Truth compute/result budgets are safety limits, not a second user setting. `truthTableCap` remains the sole user-controlled bit cap (1–24), but work is refused before execution when projected rows or retained bytes exceed fixed budgets. Paging only reveals an already-computed retained result and never computes additional rows.

Append these errors to the inherited application union:

| Code | Meaning |
|------|---------|
| `INSPECTION_NOT_READY` | Requested operation has not produced its payload |
| `INSPECTION_UNAVAILABLE` | Operation failed/refused or payload could not be retained |
| `INSPECTION_EXPIRED` | Known operation's unpinned payload was evicted |
| `TOPOLOGY_UNAVAILABLE` | Artifact lacks valid/supported bounded full topology |
| `TRUTH_TOO_LARGE` | Projected rows/result exceed fixed safety budgets |
| `TRUTH_NEEDS_SESSION` | Filtered scope requires an exact ready live session |
| `WORKBENCH_CONFLICT` | Expected settings/presentation revision changed |
| `HIGHLIGHT_NOT_FOUND` | Current root has no matching top-level name/kind join |
| `EXPORT_UNAVAILABLE` | Requested source/artifact/memory/transcript snapshot is unavailable |
| `SHARE_TOO_LARGE` | Encoded payload exceeds 8,192 characters; details report actual/key |
| `SHARE_CODEC_UNAVAILABLE` | Captured source requires deflate but browser codec failed and plain form is over cap |
| `DOWNLOAD_FAILED` | Blob/object-URL/anchor dispatch failed before a click was issued |
| `CURSOR_CONFLICT` | Text/topology/Truth cursor belongs to another immutable snapshot |

Use inherited source/target/options/artifact/session/live/image/revision, lifecycle, input-size, result-size, persistence, and operation errors. Unknown fields and unsafe integers are invalid. All cursors are opaque, page-lifetime-bound, and result-size checked.

### Schematic and topology

```ts
export interface InspectionTicket {
  operationId: OperationId;
  disposition: 'started' | 'joined' | 'already_current';
  inputs: WorkInputs;
}

export interface RequestSchematicInput {
  projectId: string;
  expectedSourceRevision: Revision;
  expectedTargetEpoch: Revision;
  expectedPreviewOptionsRevision: Revision;
}

export interface SchematicPage {
  operationId: OperationId;
  inputs: WorkInputs;
  compiler: DiagnosticCompilerIdentity;
  settings: { expandMacros: boolean; expandDisplay: boolean; color: 'never' };
  dimensions: { rows: number; columns: number; codeUnits: number; utf8Bytes: number };
  text: string;
  nextCursor: string | null;
}
```

`circ_request_schematic` captures current files/entry and `optionsFor('preview')`, creates or joins the existing preview operation before worker awaits, and does not switch views. `circ_get_schematic` accepts operation ID, optional cursor, and 1–24 KiB code-unit page target. Pages split only at Unicode scalar boundaries, preserve text byte-for-byte when concatenated, and bind the exact operation/settings/compiler. Retain at most eight/one MiB each; pin only the displayed/current preview and active page snapshot.

```ts
export interface GetTopologyInput {
  expectedArtifactId: ArtifactId;
  section: 'components' | 'connections';
  scope?: 'root' | 'flattened';
  cursor?: string;
  limit?: number;
}

export interface TopologyOrigin {
  alias: string;
  subcircuit: string;
  targetFileId: number;
  targetFile: string | null;
}
```

Topology pages include artifact/source validation provenance, topology version, total counts, scope, and either components or connections. Components expose artifact-local u32 ID, stable kind name, width, name, origins, slice/memory aux. Connections expose artifact-local source/destination IDs, numeric port byte, and resolved port label when unambiguous. `root` keeps components with no origin and connections whose endpoints both remain; `flattened` returns all records. IDs are inspection references valid only with that artifact ID and are never accepted by live mutation/highlight APIs.

Extract and validate the CIRF section before decoding: size/count/frame limits, supported version, complete input, known kinds, valid IDs/endpoints, widths/aux, and safe totals. Cache one decoded topology for the current displayed artifact; replacement releases it. Cursor pages cannot keep obsolete artifact bytes alive. Invalid topology fails as data, never partially returns plausible records.

### Truth inspection

```ts
export interface RequestTruthInput {
  projectId: string;
  expectedSourceRevision: Revision;
  expectedTargetEpoch: Revision;
  expectedTruthOptionsRevision: Revision;
  expectedImageRevision: Revision;
  expectedArtifactId?: ArtifactId;
  expectedSessionId?: SessionId;
  expectedLiveStateRevision?: Revision;
}

export interface TruthScope {
  kind: 'exhaustive' | 'filtered';
  engine: 'compiler' | 'scratch_session';
  inputBits: number;
  enumeratedBits: number;
  rowCount: number;
  cap: number;
  heldInputs: { name: string; state: SignalValue }[];
  unknownInputs: { name: string; width: number }[];
  partialBusPolicy: 'whole_bus_unknown';
}

export interface TruthPage {
  operationId: OperationId;
  inputs: WorkInputs;
  compiler: DiagnosticCompilerIdentity;
  scope: TruthScope;
  columns: { name: string; kind: 'in' | 'out'; width: number }[];
  rows: { index: number; inputs: (string | null)[]; outputs: (string | null)[] }[];
  nextCursor: string | null;
}
```

Truth preflight uses exact analysis/artifact metadata. Any root or nested RAM refuses. Errors refuse. If total input bits are at/below `truthTableCap`, scope is exhaustive: use compiler Truth for root-compatible preloads, scratch Truth when imported images require runtime application. If total bits exceed the cap, require the exact ready session supplied by Phase 4, snapshot its inputs, hold fully defined pins, treat an entire partly defined bus as unknown, and enumerate unknown bits only. Report held and unknown inputs explicitly.

Before work, compute `2^enumeratedBits`; refuse above 4,096 rows or estimated one-MiB retained output. Compiler calls remain worker-owned and non-preemptible. Scratch enumeration executes in chunks using Phase 4's cooperative scheduler, never writes live state/console, and destroys its session. Source/image/session changes after capture make results historical but cannot alter them. UI Truth and tools consume the same result; no second agent-only table pipeline.

`circ_request_truth_table` returns a ticket before awaits. `circ_get_truth_table` accepts operation ID/cursor/1–128 rows, returns only already-retained rows, and preserves compiler ordering and null unknown cells. Retain eight results/two MiB total, pinning current displayed/latest current result and active pages. One oversized row is `RESULT_TOO_LARGE`, not truncated. Assertion/verification semantics remain Phase 4 and are not inferred from a Truth row.

### Text and share handoff

```ts
export type ExportOmission =
  | 'source_images'
  | 'live_ram'
  | 'live_pin_state'
  | 'active_entry_selection'
  | 'settings'
  | 'transcript'
  | 'compiled_artifact';

export interface TextExportPage {
  exportId: string;
  contentType: string;
  text: string;
  nextCursor: string | null;
  provenance: { target: TargetRef; sourceRevision: Revision; sessionId: SessionId | null };
  contents: string[];
  omissions: ExportOmission[];
}
```

`circ_export_source` snapshots the exact active ordered files after source/target preconditions. `format: combined` uses unchanged `joinFiles` marker text; `format: files` pages complete named-file records and never splits one record unless its body uses the inherited file-text cursor. Concatenation/reassembly is exact. Results report the active entry in provenance, but the source text itself contains only ordered names/bodies and the last-file default convention; it does not encode a separately selected non-last entry. It also omits images, live state, settings, transcript, and artifact.

`circ_create_share_link` captures that same combined source, encodes with `encodeShare(webStreamsCodec())`, and constructs a URL from the current fragment-free page URL. It never reads or restores the scrubbed incoming fragment and never calls clipboard or `navigator.share`. Success reports key, payload chars, cap, source provenance, contents, and omissions, including that a non-last active entry reopens at the format's last-file default. Over-cap reports `SHARE_TOO_LARGE` with no clipboard fallback. If deflate fails, plain fallback is allowed exactly as today; if plain exceeds cap, report codec/size truth.

`circ_get_transcript` snapshots Phase 4's current transcript ID/revision and accepts `format: log | script`, cursor, and line limit. Log preserves all lines; script preserves only echoes without `> ` and comments. Pages split by complete lines, report retained-start truncation when the 2,000-line ring dropped older lines, and bind target/session span and transcript revision. Reading neither opens nor clears the console.

### Binary downloads

```ts
export interface DownloadReceipt {
  dispatchId: string;
  state: 'dispatched';
  filename: string;
  mediaType: 'application/wasm' | 'application/octet-stream';
  bytes: number;
  provenance: { target: TargetRef; artifactId: ArtifactId | null; sessionId: SessionId | null; liveStateRevision: Revision | null; imageRevision: Revision | null };
  contents: string[];
  omissions: ExportOmission[];
  completionKnown: false;
}
```

`circ_download_artifact` requires exact artifact ID, copies bytes before Blob construction, generates the existing safe artifact filename, dispatches one hidden-anchor click, and revokes the URL on the existing delay. It may export an identified stale last-good artifact only when the caller names that artifact and result labels source freshness. WASM contains runtime/topology for its build, never source-image bytes, live RAM/pins, settings, or transcript.

`circ_download_memory` has a discriminated source. `live_root` requires exact artifact/session/live revision and root memory name, synchronously calls the shared session's `storeImage`, copies bytes, and names `<memory>.bin`. `source_preload` requires exact project/source/image revisions plus file/declaration and exports the stored ROM prefix, including an intentional zero-byte clear image; it supports imported-file owners without live nested access. Both use raw little-endian words and state that undefined live bits become zero, so the file does not preserve defined masks.

Preflight names, result size, identities, and download capability before obtaining/mutating object URLs. Once `anchor.click()` returns, receipt state is only `dispatched`; no browser API proves completion/path. One call dispatches exactly one file. Existing human buttons retain their behavior through the same download helper but do not require agent preconditions.

## Execution & Concurrency Model

- The controller owns revisions, operation links, presentation state, and public orchestration. The compiler worker owns preview/compiler Truth. Phase 4's scheduler owns scratch Truth and session snapshots. The current artifact owns topology bytes. The store owns settings/view/source images. The console owns its bounded transcript. The island owns DOM highlighting and download dispatch.
- Schematic/Truth request methods validate and allocate operation records before awaits, capture all files/options/images/live pins by value, and recheck ownership after every await. Exact queued/running calls join; exact retained terminal calls reuse. Late work stays historical and cannot replace a newer UI result.
- Topology and export reads are synchronous over immutable snapshots except async share compression. Share captures source/base URL before awaiting; a later edit does not rewrite its returned provenance. Text cursors hold bounded snapshots under inherited retention and lifecycle rules.
- Settings/view commits are synchronous and non-reentrant. Agent persistence flush happens after coherent visible state. Async work they schedule cannot roll back settings. Highlight application is synchronous and transient; temporary human overlays are presentation state, not concurrent source mutations.
- Scratch Truth yields in bounded chunks and checks deadline/lifecycle/operation ownership; compiler Truth cannot be aborted. Timeout of `circ_wait_for_operation` remains a wait timeout. No cursor retrieval starts computation.
- Download byte capture and anchor dispatch occur in one coordinator call. Artifact/session/image preconditions are rechecked immediately before copying. No unrelated UI mutation can interleave within that JavaScript turn.

## Persistence & I/O

No schema/key change. Existing schema-v2 settings, editor preferences, view, and Data state persist under `localStorage['circ.playground.v1']`; agent changes return Phase 3 persistence receipts. Inspection payloads, topology caches, highlights, export snapshots/cursors, transcript identities, and download receipts remain page-memory only. Reload creates new identities and clears these ephemeral records.

Share output is a URL fragment containing combined source under `src` or `src0`, capped at 8,192 payload characters and scrubbed on load before analytics. It is returned to the connected agent but not sent to an application backend. It excludes images and live state.

WASM/memory exports use browser Blob/object-URL/anchor download I/O only. No filesystem path, completion callback, server upload, clipboard, share sheet, remote API, backend, relay, or WebSocket is introduced. Documentation must distinguish local generation from data returned to the connected agent and bytes offered to the browser download manager.
